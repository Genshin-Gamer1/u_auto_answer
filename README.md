## 安全说明

- 本脚本会将作业题目、选项及启用图片识别时的相关截图发送到用户自行配置的模型 API。
- API Key 和答案缓存仅保存在当前浏览器的 Tampermonkey 本地存储中，不会写入脚本源码。
- 本脚本不包含作者自建的数据上报、访问统计或远程日志服务。
- 使用前请检查脚本源码，并从可信的 GitHub 仓库安装。
- 请勿在不可信的网页环境中填写 API Key，也不要将 API Key 发布到 GitHub、Issue、截图或日志中。
- 本脚本不会主动点击“提交作业”，但平台可能自动保存草稿；填写后请人工检查并自行决定是否提交。
- AI 生成的答案可能不准确，模型返回的置信度不代表答案一定正确。
